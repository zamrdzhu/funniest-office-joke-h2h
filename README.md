The funniest one-line office joke, written for make.fun's "The Funniest Office Joke, Judged Head to Head" bounty.

## The line

> Our printer only jams on deadline day, so HR gave it a performance review — it scored higher than me.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

It works because it is built on something anyone who has worked in an office recognises — the printer that only jams when it matters — and the turn is genuinely surprising: instead of fixing the printer, HR reviews it. The punchline lands last, and it stings because it is plausible: the machine that sabotages you still outranks you. One line, 101 characters, well inside the 200-character gate. The joke is fresh because the printer is not the butt of it — the performance-review system is.
